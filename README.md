# 🎵 SoundScape Symphony - Interactive Audio Visualizer

A stunning web-based audio visualizer that transforms sound into mesmerizing visual experiences. Built with modern web technologies, this application offers 20+ unique visualization modes with customizable presets and real-time audio processing.

![Soundscape Visualizer](https://img.shields.io/badge/Interactive-Audio%20Visualizer-blue) ![Web Technologies](https://img.shields.io/badge/HTML5-CSS3-JavaScript-orange) ![Real-time](https://img.shields.io/badge/Real--time-Processing-green)

## ✨ Features

### 🎨 Visualization Modes
- **Classic Bars** - Traditional frequency spectrum bars
- **Circular** - Radial audio visualization
- **Wave** - Smooth waveform display
- **Spectrum** - Frequency spectrum analysis
- **Particles** - Dynamic particle system
- **3D Terrain** - Three-dimensional landscape
- **Guitar Hero** - Music game-inspired display
- **Starfield** - Space-themed visualization
- **Frequency Mesh** - Mesh network visualization
- **Energy Orbs** - Floating orb particles
- **Ripple** - Water ripple effects
- **Waveform** - Classic audio waveform
- **Fractal** - Mathematical patterns
- **Spiral** - Spiral patterns
- **Bubbles** - Floating bubble effects
- **Fireflies** - Animated firefly particles
- **Grid** - Matrix-style grid
- **Tunnel** - 3D tunnel effect
- **Galaxy** - Cosmic galaxy visualization
- **Matrix** - Digital rain effect
- **Surface 3D** - Interactive 3D surface

### 🎛️ Controls & Customization
- **Real-time Recording** - Capture audio from microphone
- **Preset System** - Multiple visual themes (Neon, Minimal, Dark, Retro, Default)
- **Color Customization** - Adjust primary, secondary, and background colors
- **Sensitivity Control** - Fine-tune audio input sensitivity
- **Animation Speed** - Control visualization animation speed
- **Intensity Adjustment** - Modify visual effect intensity
- **Fullscreen Mode** - Immersive viewing experience

### 🎯 Specialized Settings
- **Matrix Mode** - Customizable digital rain with font size, speed, and character set
- **Starfield Themes** - Multiple space-themed visualizations
- **Surface 3D Controls** - Color maps, perspective, and rotation settings

## 🚀 Quick Start

### Prerequisites
- Modern web browser with microphone access
- Node.js (optional, for local development)

### Installation
1. Clone or download this repository
2. Open `index.html` in your web browser
3. Allow microphone access when prompted
4. Start making noise and watch the magic happen!

### Using the Starter Script
For local development with live reload:
```bash
# Run the starter script
./starter.bat
# Or manually:
npx serve
```

## 🎮 How to Use

1. **Select Visualization**: Choose from 20+ visualization modes
2. **Choose Preset**: Apply different visual themes
3. **Start Recording**: Click the record button to capture audio
4. **Adjust Settings**: Fine-tune sensitivity, speed, and intensity
5. **Customize Colors**: Use color pickers for personalization
6. **Go Fullscreen**: Click fullscreen for immersive experience

## 🎨 Customization

### Adding New Visualizations
1. Add new option to `visualizationType` select element
2. Implement corresponding rendering function in JavaScript
3. Add any specialized controls if needed

### Creating New Presets
1. Add new preset button to HTML
2. Define preset configuration in JavaScript
3. Handle preset application logic
